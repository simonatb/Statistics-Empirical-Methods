### 32  Генерирайте 500 случайни числа от равномерно разпределение в интервала (3 5). Начертайте хистограма на генерираните числа и на същата картинка добавете графика на плътността на случайна величина X ∼ U(3 5). Повторете същото с 5000 случайни числа
```
samples <- runif(500,3,5)
hist(samples, probability=T )
curve(dunif(x, 2, 3), from=2, to=3, add=T, lwd=2.5 )
```
### 33 Генерирайте 500 случайни числа от експоненциално разпределение с параметър l = 1 / 7.Начертайте хистограма на генерираните числа и на същата картинка добавете графика на плътността на случайна величина X ∼ Exp( = 1 7). Повторете същото с 5000 случайни числа.
```
samples <- dexp(500,1/7)

```
